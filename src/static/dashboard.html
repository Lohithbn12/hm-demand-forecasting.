How to read this page

Forecast. How many units the model expects to sell over the next 4 weeks.

Safety stock. Extra units kept as a cushion, because forecasts are never exact. Harder-to-predict categories get a bigger cushion.

Order up to. Forecast + safety stock. Stock on hand plus on order should reach this level.

Class (e.g. AX). First letter = importance by revenue (A highest). Second letter = how steady demand is (X steady, Y moderate, Z very variable or seasonal).

Service goal. The target chance of not running out of stock during the 4 weeks. Important categories get a higher goal.

Order quantity. Order up to, minus what you already hold, minus what is already on order.

  • Demo data: H&M sales 2018–2020. City (Stockholm) is an assumption because the dataset has no store location.
  • The model's average forecast error was about 23% (WAPE) on a 24-week backtest, so treat numbers as planning estimates, not exact predictions.
  • The H&M data has no inventory. Stock figures in the calculator are numbers you type in.
